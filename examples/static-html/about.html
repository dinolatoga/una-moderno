A journal you can take apart.

Una Moderno is a portable editorial layout system for the independent web. This specimen lets you see what its HTML and CSS can do before choosing a framework or a publishing platform.

Fictional words, working pages

All stories, publication details, and authors in this edition are fictional demonstration material. The illustrations are original geometric SVG artwork made for this repository. There are no borrowed historical assets.

Where it began

Una Moderno descends from Dino Latoga's 2008 Una WordPress theme. It retains the distinctive editorial proportions and featured-story rhythm while rebuilding the implementation around semantic HTML and a shared CSS token contract.

Built to be reused

The core needs no JavaScript or framework. An optional Tailwind layer and an Astro reference show how the same visual contract can travel. WordPress is a future adapter target; a live EmDash integration is not claimed.

Get the source, documentation, and MIT license on GitHub.

Type and artwork

The display type is Bricolage Grotesque, by Mathieu Triay and contributors, distributed under the SIL Open Font License. The core's optional font stylesheet loads a bundled Latin subset. Body text uses local system fonts.
