## Geist Sans

`packages/core/assets/geist-variable.woff2` is the unmodified normal variable font from Vercel's official [`geist@1.9.0` npm distribution](https://www.npmjs.com/package/geist/v/1.9.0), archive member `package/dist/fonts/geist-sans/Geist-Variable.woff2`. The [official project release](https://github.com/vercel/geist-font/releases/tag/v1.9.0) identifies the release; the npm binary's embedded version is **1.900**. The font checked into the GitHub tag has a different embedded version, so this repository deliberately records the actual npm binary, not an assumed identical GitHub asset.

- Archive: <https://registry.npmjs.org/geist/-/geist-1.9.0.tgz>. The downloaded archive matched npm's published SHA-512 integrity value.
- Font: 69,576 bytes; SHA-256 `5c5588027e59e74e205b9d6c7fd877b261091cee367f6bb3a8d505da14cae512`.
- Axis: `wght` 100–900, default 400. The specimen uses 400, 700 and 800. This is the full upstream WOFF2, not a newly generated language subset; only this one font asset is loaded.
- Embedded copyright: © 2024 The Geist Project Authors. Font software is **SIL Open Font License 1.1**, not MIT.
- [OFL.txt](../packages/core/assets/OFL.txt) preserves the [release's license](https://github.com/vercel/geist-font/blob/v1.9.0/OFL.txt) (SHA-256 `c683bfbcc7e087f5d37a54ef628f10387c451a83ddc459b151403a164ac46c90`). [Geist-LICENSE.txt](../packages/core/assets/Geist-LICENSE.txt) also preserves the npm distribution's notice, including its 2023 Vercel/basement.studio copyright (SHA-256 `930853ee1daa68554d9e35c8a9175affb74f699fad9a5da6ee5ebe76379d9137`).

[Machine-readable provenance](../packages/core/assets/provenance.json) records the same binary and metrics. No font code was executed and no framework dependency was installed to use it. There are no external runtime font requests. All four canonical font roles resolve to Geist; the optional `fonts.css` entrypoint uses `font-display: swap`. If it is omitted or the font fails, local/system sans remains readable. Italic emphasis uses the browser's normal synthesis from the shipped upright face; there is no unused italic, mono, or former display-font download.

The optional local fallback uses Arial/Arial Bold only when already installed; those system files are not redistributed. Read-only table inspection found units-per-em 2048 and x-height 1062 in both faces. Geist's units-per-em is 1000, x-height 530, ascent 1005, descent 295, and line gap 0. Thus `size-adjust = (530/1000)/(1062/2048) = 102.2072%`, `ascent-override = 100.5/1.0220716 = 98.3297%`, `descent-override = 29.5/1.0220716 = 28.863%`, and `line-gap-override = 0%`. These align x-height and vertical metrics; they do not promise identical glyph widths or eliminate all layout shifts. A system-sans stack follows when local Arial is unavailable.
