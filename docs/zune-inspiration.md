# Zune desktop inspiration

The owner selected Zune 4.0's **light Collection view** and a **Zune HD website screenshot** as references for Una Moderno's direction. The desktop image shows artists, album artwork and songs in aligned columns on an open, near-white canvas. The website image adds a dark lead field inside a light document, large thin headings, lowercase navigation and unboxed columns below. Both inform visual grammar; neither is a template to clone.

The second image visibly includes Zune HD device photography, product marketing and a 2010 copyright footer. That footer does not establish the screenshot's capture date. Una translates its dark lead field into an editorial story treatment while retaining a light article-reading surface. The reference images remain outside the repository; no local attachment paths are part of the public documentation.

Una Moderno remains an independent editorial layout system. It is not affiliated with, sponsored by, or endorsed by Microsoft. Microsoft, Zune and other referenced names and marks belong to their respective owners.

## Interpretation for Una Moderno

| Observed in the pinned references                                        | Editorial interpretation                                                                  |
| ------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------- |
| Open light ground with little enclosing chrome                           | Keep stories and useful sidebar content on a continuous reading surface.                  |
| Compact category labels alongside larger, lighter typography             | Establish hierarchy through type size and weight instead of additional panels.            |
| Precisely aligned content columns                                        | Use Una's exact 1.618:1 editorial split, leading story and three recent stories.          |
| Artwork supplies most visual color                                       | Let original editorial illustrations carry expression; keep interface accents restrained. |
| Dark active labels, quieter secondary labels and small saturated accents | Make navigation state clear while preserving contrast and visible keyboard focus.         |
| Website's dark lead field within a light page                            | Use an optional dark index-story cover; preserve the light long-form reading surface.     |
| Website's thin large headings and borderless columns                     | Give sections clear typographic scale without introducing a generic card grid.            |

These mappings are modern design decisions, not recovered Zune specifications. The owner's current choice is **Inter for every text role**: weight 200 for the wordmark, 300 for display/navigation, 400 for body, 500 for metadata and 600 for current navigation, compact headings and inline prose links. Inline prose links are italic/600, distinguishing them from upright strong text, and retain that weight on hover. The dark cover headline is paper-colored at rest and rose on hover at a stable weight 300. Inactive navigation is muted/300 and turns rose/300 on hover; only the current page is rose/600. Noninteractive module headings use ink. These are Una choices, not historical font or behavior claims. The single navigation collection reads journal, stories, long read and about. Quickplay's panoramic music dashboard and generic Metro tile grids are outside this direction.

The references contain visible rules and separators. The owner explicitly chose to omit those in Una: no decorative dividers on navigation, modules, sections, contents or footer, no masthead stripes, and no link underlines in any state or simulated with borders, pseudo-elements, shadows or gradients. Color, weight and the italic prose-link treatment provide cues; the 3px keyboard focus outline remains. The wordmark uses two separate unbroken words with a 16vw phone-size cap, and the utility line is hidden without reserved space at 30rem and below. This is a deliberate adaptation, not a claim that historical Zune interfaces had no lines or shared these responsive behaviors.

The current owner refinement uses exact 1.618:1 tracks, a fluid 3rem–5rem column gutter and a separate 2.5rem stacked row gap. Display/navigation/heading sizes are 80% of the preceding Una scale; reading and metadata sizes remain unchanged. These values are current Una decisions, not measurements recovered from either Zune screenshot. Una's historical 580:360 split and 20px gap remain documented origin evidence.

Five owner-approved generated panoramas supply optional page backgrounds. These were generated for Una under Dino’s direction and approved in the session, not copied from Zune assets. Exact PNG masters are retained and WebP derivatives preserve the full scenes without cropping, recoloring or regeneration. Their imagery does not add interface dividers or link decoration. The full-width scene, 39vw content offset and bottom-only paper blend are current Una decisions rather than recovered Zune measurements. A single allowlisted choice is made in markup or at build/server time, without random client behavior; see [artwork provenance](assets.md#optional-page-artwork).

The About pages intentionally point to the owner's durable GitHub `main`-branch URL for this document. During unmerged branch review that destination is not yet available on `main`; this repository-relative document is the current record. No merge or publication is implied by the link.
